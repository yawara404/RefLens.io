# RefLens.io｜探す・集める・構想するをつなぐリファレンスボード

## 💡 概要

RefLens.io は、**pixiv や Web 上の画像資料をブックマーク感覚で集め、無限キャンバスで並べて見比べられる Web アプリ**です。「探す（View）」「集める（Manager）」「構想する（Canvas）」の3つのワークフローをひとつの場所につなぎ、資料探しから制作前の構想までをブラウザで完結させます。

## 🎯 開発背景（Why）

趣味でイラストを描くなかで、資料を探す時間と、集めた資料を制作中に見返す手間を減らしたいと考えて作りました。資料集めでブラウザのタブが30個以上開いて作業環境が散らかる、ローカルフォルダに保存した資料は埋もれて描くときにすぐ出てこない、PureRef などのデスクトップアプリは優秀でも Web からの取り込みやスマホ・別端末との同期が手間、という3つの困りごとがありました。

「Web 上で見つけた資料をその場でストックし、同じ画面上のキャンバスで並べて見比べ、構想を固める」。その流れをブラウザひとつで途切れさせないために作りました。

## 🚀 主な機能

### 1. pixiv で探し、ページを送って集める

おすすめ・ランキング・キーワード検索・フォロー・ブックマークから作品を探せます。ページ番号・最初へ・前後移動をまとめたページャーを結果の上部と下部に置き、ページを変えると結果の先頭へ戻ります。おすすめ・人気・検索ではページ番号を指定でき、フォロー・ブックマークはカーソル方式のため前後1ページずつ進みます。気に入った作品はフォルダを選んで保存するか、そのままキャンバスへ送れます。

### 2. フォルダとタグで整理し、キャンバスへ運ぶ

Web の URL、手元の画像、pixiv 作品を保存し、フォルダとタグで整理できます。カード左上には pixiv・Instagram・Web の出典バッジと選択チェックをまとめ、複数選択から一括のフォルダ移動・キャンバス配置・削除ができます。検索欄では pixiv の人気タグや保存済み資料の解析タグを候補として表示し、目的の資料にたどり着きやすくしています。ログイン前でもサンプル資料とキャンバス操作を試せるデモモードを用意しました。

### 3. 無限キャンバスで並べて見比べる

マウスホイールやドラッグで無限に広がるキャンバスを移動し、画像を自由に配置できます。移動・四隅リサイズ・自由回転（15度スナップ）・左右反転・上下反転に対応し、ポーズ、配色、光の当たり方、衣装のディテールをひとつの視界に並べて比較できます。グレースケール表示で明度を確認し、参考画像から主要5色を抽出してカラーコードをコピーできます。グリッド整列や水平・垂直の整列で、集めた資料を短時間でレイアウトできます。

### 4. AI 解析とキーボード操作で構想を詰める

資料を選ぶと、構図・ライティング・ポーズ・衣装・配色をAIが読み取り、解析パネルに表示します。Ollama または Gemini を使い、失敗時は画像特徴量による解析へ切り替わります。ペンタブを握ったまま左手だけで操作できるショートカットを用意し、ダイアログ表示中や文字入力中は背面のキャンバス操作が反応しないようにしています。

## 🌟 工夫した点

1. **入力操作とキャンバス操作を分ける**  
   検索欄への入力やダイアログの操作中に背面の画像が動かないよう、フォーカス制御とショートカットの判定を共通化しました。ダイアログ内ではTabキーの移動を循環させ、閉じた後は呼び出し元へフォーカスを戻します。
2. **資料を見比べるための背景**  
   キャンバスには方眼とドットの背景を用意しました。画像の水平・垂直や大きさを確認する目安にしつつ、パンやズームで背景自体が動き続けない表示にしています。
3. **編集途中の変更を残す自動保存**  
   保存リクエストを順番に処理し、保存中に加わった編集も未保存の変更として保持します。保存が失敗したときは変更を残し、再試行できるようにしました。
4. **画面の高さを固定し、一覧だけをスクロールする**  
   アプリ画面は表示領域の高さに合わせ、ヘッダーと操作バーを固定したまま一覧部分だけをスクロールさせます。ウィンドウ全体が動かないため、スマホでも下端に不要な余白や見切れが出ません。ヘッダーはPC幅で3カラムに切り替え、狭い画面では補助ボタンを絞って文字や操作が重ならないようにしました。
5. **探索を止めないページ送り**  
   ページ番号・最初へ・前後移動・ページ指定を共通コンポーネントにまとめ、読み込み中も操作状態を保ちます。ページを変えたときは結果の先頭へ戻し、再読み込みでも現在ページを維持します。pixiv API のページ上限（100）とカーソル方式の制約をUIに反映し、進めないページは押せないようにしています。
