# RefLens.io｜システム構成

### 🛠️ アーキテクチャ概要

RefLens.io は、pixiv や Web で見つけた画像を保存し、無限キャンバスで並べて見比べられるリファレンスボードです。Nuxt 3 が画面とキャンバス操作を、FastAPI が認証・保存・解析を担当します。資料と配置は SQLite、画像本体は Cloudflare R2 に保存し、公開は本番ビルドを Cloudflare Tunnel 経由で配信します。2026年11月24日時点で、公開URLの View 画面を PC幅 1440×900 とスマホ幅 390×844 で確認し、ページ送り・内部スクロール・画像の再表示が動作しています。自動テストはバックエンド40件・フロントエンド29件、TypeScript の型チェックと本番ビルドも通っています。

| レイヤー | 技術スタック | 選定理由・特徴 |
| :--- | :--- | :--- |
| **フロントエンド** | Nuxt 3・Vue 3（Composition API）・TypeScript | 「探す（View）」「集める（Manager）」「構想する（Canvas）」の3画面をコンポーネント化。PCとスマホで同じ操作系を使える。 |
| **状態管理** | Pinia | キャンバス上の画像の位置・サイズ・回転・重なり順・選択状態を管理。連続する編集の保存リクエストを順番に処理する。 |
| **キャンバス操作** | Pointer Events・CSS Transform | パン・ズーム・ドラッグ・リサイズ・回転・反転をブラウザだけで扱う。変形は変換行列として保持し、画像を読み直さずに反映する。 |
| **検索サジェスト** | 自作コンポーザブル `useSearchSuggest.ts` | pixivの人気タグと、保存済み資料に付いた解析タグを横断して候補表示。入力中でも目的の資料にたどり着きやすくする。 |
| **ページ送り** | 自作コンポーネント `PixivPager.vue` | ページ番号・最初へ・前後移動・ページ指定・読み込み中表示を共通化。Viewの上部と下部、取り込みモーダルで共用する。 |
| **アクセシビリティ** | 自作コンポーザブル `useDialogA11y.ts` | ダイアログ内のフォーカス循環、閉じた後のフォーカス復帰、背面ショートカットの抑止を共通化する。 |
| **バックエンドAPI** | Python・FastAPI・SQLAlchemy | 認証、資料・ボード・配置の保存、画像取得、解析処理を担当。ボードの参照・変更時に所有者を確認する。 |
| **画像解析** | Ollama・Google Gemini API・Pillow | 構図・光・ポーズ・衣装・配色を解析。設定したプロバイダを使い、失敗時は画像特徴量による解析へ切り替える。 |
| **データベース** | SQLite | アカウント、ブックマーク、フォルダ、ボード、画像の配置、解析結果を保存。ローカル用・公開用・pixivローカル用でDBを分ける。 |
| **画像ストレージ** | Cloudflare R2・boto3（S3互換API） | 画像本体を保存。R2未設定時はローカル保存でも動く。既存の `/uploads/` パスを保ったまま保存先を移行できる。 |
| **外部連携** | pixiv連携 | 接続したアカウントで作品を検索・取得し、ManagerやCanvasへ取り込む。未接続時はデモフィードを表示する。 |
| **公開・運用** | Cloudflare Tunnel・launchd・Nitro | 本番ビルドをトンネル経由で公開。ローカルのAPIとフロントはlaunchdで常駐し、異常終了時は自動復旧する。 |

### 🔧 実装のポイント

1. **画像をR2に置いたまま、既存の画像パスを守る**  
   アップロード画像と取り込み画像はバックエンドからR2へ保存します。R2の公開ドメインは使わず、従来の `/uploads/` パスからバックエンド経由で配信するため、保存先を移行しても既存のブックマークとキャンバスの画像パスは変わりません。AI解析で画像ファイルが必要なときはR2から一時取得し、処理後に削除します。
2. **キャンバスの編集を失わない自動保存**  
   位置・サイズ・回転などの変更を保存リクエストのキューに積み、順番に処理します。保存中に加わった編集も未保存の変更として保持し、失敗したときは変更を残して再試行できるようにしました。
3. **資料を探し直すためのAI解析**  
   画像生成ではなく、構図・ライティング・ポーズ・衣装・配色の読み取りに使います。解析結果とタグは検索に利用でき、自動タグ付けは設定から切り替えられます。外部APIが使えない場合は画像特徴量による解析へ切り替わります。
4. **ページを変えても探索を止めないページ送り**  
   ページ番号・最初へ・前後移動・ページ指定を共通コンポーネントにまとめ、検索結果の上部と下部に置きました。おすすめ・人気・検索はページ番号で移動でき、フォロー・ブックマークはカーソル方式のため前後1ページずつ移動します。ページ変更後は結果の先頭へ戻り、再読み込みしても現在ページを維持します。
5. **画面の高さを固定し、一覧だけをスクロールする**  
   アプリ画面は表示領域の高さに合わせ、ヘッダーと操作バーを固定したまま一覧部分だけをスクロールさせます。ウィンドウ全体が動かないため、スマホでも下端に不要な余白や見切れが出ません。ページ送りの読み上げ用要素もページャー内に収め、ページ全体のスクロール領域を広げないようにしています。
6. **共有している画像を消さない**  
   資料を削除するときは、同じ画像を参照する資料が残っていないか確認します。ローカル用・公開用・pixivローカル用のDBで共有している画像も確認し、参照が残る画像やデモ用の共通画像は削除から保護します。既存画像の移行ツールは、ローカルとR2の内容を照合し、同名で内容が異なる場合は上書きせずに停止します。
