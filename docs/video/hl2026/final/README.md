# RefLens.io プレゼン動画・60秒テロップ版

完成動画: RefLens_HL2026_60s_captioned.mp4
1920×1080 / 30fps / H.264 / 正確に60秒 / 音声なし

実アプリで収録したデモ写真3枚を使用。画面全体を90%に縮小し、操作UIを隠さない下部帯に説明テロップを追加しました。冒頭から実画面を表示します。

## 構成
0〜5秒: キャンバス全景とコピー
5〜12秒: サービス紹介
12〜24秒: 資料ライブラリ・詳細プレビュー
24〜32秒: 資料ブラウザ
32〜44秒: 資料移動・白黒比較
44〜54秒: パン・ズーム
54〜60秒: コピー・公開URL

## 編集用ファイル
narration.txt: VOICEVOX用のナレーション案（未合成）
captions.srt: ナレーション案と同文の字幕（焼き込みテロップとは別）
graphics/: テロップ帯と締め画面のPNG
source_clips/: 字幕なしの元クリップ5本（ZIP内）

Canvaで別途作成した編集可能なタイトル・エンドカード:
https://canva.link/apbd0dr1id5grjy
Canvaカードは差し替え用で、MP4の締め画面にはローカルで作成したデザインを使用しています。

今回の使用: Playwright・FFmpegによる実画面収録/編集、Canvaによる差し替え用カード作成。
ChatCutは接続先が見つからず、使用していません。Adobeはこの編集には使用していません。
pixiv実検索・保存やAI推論処理の実行は素材に含みません。詳細プレビューの分析文はデモに含まれる既存テキストです。

検証: 60秒・1080p・30fpsをffprobeで確認、各場面の書き出しフレームを目視確認。音声の生成・録音は行っていません。
